## 安全检查

- `.env`、`.env.*`、日志、构建产物和依赖目录已忽略。
- `.env.example` 只包含占位符，没有真实 AppId/Secret。
- Fastify 日志配置脱敏 authorization、code、anonymousCode、token、sessionKey。
- 生产环境缺少 AppId 或 AppSecret 时快速失败。
- 当前响应不包含 openid、session key 或密钥。
