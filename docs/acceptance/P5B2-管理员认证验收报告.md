## 真实本地链路

使用内存持久化及环境变量初始化临时超管，通过真实 HTTP 和管理后台完成：

1. 未登录 `GET /admin/v1/auth/me` 返回 401。
2. `POST /admin/v1/auth/login` 返回 200，并由浏览器接收 HttpOnly Cookie。
3. 后台进入仪表盘并显示服务端返回的管理员名称。
4. 刷新页面后 `GET /admin/v1/auth/me` 返回 200，会话恢复成功。
5. `POST /admin/v1/auth/logout` 返回 200，页面回到登录页。
6. 退出后再次读取会话返回 401，新开页面控制台无错误。
