# P2C1 CloudBase Run 部署包审计

日期：2026-09-16

## 审计

- 官方当前的 CloudBase Run 源码部署要求仓库包含 Dockerfile，并支持通过 CLI 设置服务端口、副本数和访问策略。
- 后端原仓库没有容器构建文件，不能直接作为 CloudBase Run 源码包发布。
- 本地 `.env.wechat.local` 的 `HOST=127.0.0.1` 适合本机运行，但容器内必须覆盖为 `0.0.0.0`。
- CloudBase CLI 3.8.2 可正常运行，但本机尚未登录；本阶段不创建云端服务，也不上传本地 Secret。

## 执行

- 新增 Node.js 22 多阶段 Dockerfile：构建阶段编译 TypeScript，运行阶段只安装生产依赖。
- 运行容器使用非 root 的 `node` 用户，并包含 `/health` 容器健康检查。
- 新增 `.dockerignore`，排除所有 `.env`、Git、依赖、构建产物、测试和文档，避免密钥或无关文件进入构建上下文。
- 固化微信首发服务名、端口、0～1 副本、环境变量和真实登录验收清单。

## 后台影响

无接口和数据字段变化。后续管理后台部署应使用独立服务和独立管理员鉴权，不能复用玩家 API 容器的公网权限作为管理入口。
