# P5B2 管理员认证审计

## 范围

- RBAC 仅保留 `admin` 与 `operator`。
- 管理员账号、会话、审计与玩家身份完全隔离。
- 首版只交付登录、当前会话和退出；玩家管理接口不在本阶段虚构。

## 安全决策

- 密码使用随机盐的 scrypt 哈希，数据库不保存明文。
- 会话使用 256 位随机 token，数据库只保存 SHA-256 哈希。
- token 只通过 HttpOnly、SameSite=Strict Cookie 返回，响应正文不含 token；生产 Cookie 增加 Secure。
- 带 Origin 的管理写请求必须匹配 `ADMIN_WEB_ORIGIN`，同时降低登录 CSRF 风险。
- 同一 IP 和账号 15 分钟内失败 5 次后限流。
- 登录与退出写入追加式管理审计日志。
- 初始超管只通过 Secret 环境变量创建；账号已存在时不覆盖密码。
- 管理认证变量未配置时不注册管理路由，不改变现有玩家服务行为。

## 权限边界

- `operator`：玩家/存档/指标/错误只读、普通配置写入及临时封禁。
- `admin`：包含全部运营权限，额外具备管理员管理、存档回滚及生产配置发布。
- 前端权限只用于体验控制，后续每个管理 API 必须在服务端校验权限。
