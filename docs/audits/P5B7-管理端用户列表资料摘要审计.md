# P5B7 管理端用户列表资料摘要审计

## 审计日期

2026-09-20

## 需求

用户管理列表增加微信昵称、微信头像和创建时间，便于管理员快速识别用户。

## 现状

- `createdAt` 已由 `GET /admin/v1/players` 返回，前端尚未展示。
- 昵称头像存放于独立 `player_profiles` 集合，原列表接口只查询云存档摘要，不查询资料。
- 用户详情接口已经具备同一份资料读取权限和脱敏边界。

## 执行方案

- 列表接口为当前页用户并行读取资料摘要和云存档摘要。
- 资料只返回 `nickName/avatarUrl/updatedAt`；未授权资料时返回 `profile=null`。
- 不返回 openid、unionid、token、完整云存档或其他微信资料。
- 不修改数据库结构，不把昵称头像重复写入 `players`。
- V1 默认每页 20、最大 50，后台低频使用；新增每行一次资料读取可接受。数据量增长后再评估批量查询或受控冗余。

## 管理后台影响

前端列表新增微信昵称、微信头像和创建时间三列，头像失效或资料未授权时展示占位。
